# GenZSlangSentimentAnalysisModel

A beginner-friendly NLP project that predicts whether a message has positive or negative sentiment. It includes a small set of Gen Z slang normalizations, a Scikit-learn model, and a Streamlit web app.

## Run locally

1. Install Python.
2. Open this folder in VS Code.
3. Open the terminal and run:

   `pip install -r requirements.txt`

4. Train the model:

   `python train.py`

5. Start the app:

   `streamlit run app.py`

## Example messages

- `no cap this is fire`
- `that take is mid`
- `you ate that`
- `that's cringe`

## Note

This is a small educational demo, not a full understanding system. Slang changes quickly, and context, sarcasm, and new phrases can lead to incorrect predictions. No API key is required.
